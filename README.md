# Кушетка для iPhone и iPad

Рабочий кабинет спортивного массажиста и тренера: клиенты, запись, замеры, анализы, питание, программы тренировок, справочники массажа, тренировок и питания, библиотека книг с поиском по тексту и перевод на русский. Без ИИ — только формулы, таблицы и правила.

**Открыть:** https://voodoobroodoo.github.io/kushetka-app/

## Как поставить на iPhone

1. Откройте ссылку в **Safari**.
2. Нажмите «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запускайте Кушетку с экрана «Домой»: она откроется без адресной строки и будет работать без интернета.

Нужна iOS 16.4 или новее. При первом запуске приложение сохраняется на устройстве (~6 МБ), дальше фоном докачивает тексты книг, поисковый индекс, картинки справочников и базу продуктов (~55 МБ).

## Где данные

Клиенты, записи, абонементы, заметки и настройки хранятся **в самом приложении на этом устройстве** (IndexedDB) — не на сервере и не у разработчика. Раз в день приложение само делает копию внутри себя (30 последних). Раздел «Данные» → «Сохранить копию в „Файлы“» сохраняет файл JSON в «Файлы» или iCloud Drive; его же можно загрузить в Windows-версию, веб-версию или на другой iPhone. Если удалить Кушетку с экрана «Домой», iOS сотрёт и её данные — сохраняйте копию.

## Библиотека

Тексты книг, индекс поиска, PDF, картинки справочников, база продуктов и модель перевода лежат в папке на Google Диске владельца, открытой по ссылке. Приложение читает их через Google Drive API ключом, который разрешает только чтение Диска и только с этого адреса, — входить в Google не нужно. В папке только книги под открытыми лицензиями (Creative Commons, общественное достояние, OGL, официальные документы); закрытые книги в приложении видны описанием и ссылкой.

## Устройство

Страница та же, что у Windows- и веб-версии Кушетки. Service worker (`sw.js`) хранит приложение для работы без интернета и выполняет роль «помощника» Windows-версии: данные — в IndexedDB, библиотека — с Google Диска с кэшем, перевод — движок Bergamot (Mozilla) прямо на устройстве, PDF — PDF.js по кускам файла.

Исходники — в приватном репозитории `kushetka` (папка `kushetka/ios`); эта папка собирается скриптом `ios/build.py`. Лицензии компонентов — `LICENSES.txt`.
