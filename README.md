# Кушетка для iPhone и iPad

Рабочий кабинет спортивного массажиста и тренера: клиенты, запись, замеры, анализы, питание, программы тренировок, справочники массажа, тренировок и питания, библиотека книг с поиском по тексту и перевод на русский. Без ИИ — только формулы, таблицы и правила.

**Открыть:** https://voodoobroodoo.github.io/kushetka-app/

## Как поставить на iPhone

1. Откройте ссылку в **Safari**.
2. Нажмите «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запускайте Кушетку с экрана «Домой»: она откроется без адресной строки и будет работать без интернета.

Нужна iOS 16.4 или новее. При первом запуске приложение сохраняется на устройстве (~11 МБ), дальше само, пока есть интернет, докачивает тексты книг, поисковый индекс, картинки справочников и базу продуктов (~52 МБ). Модель перевода (~45 МБ) скачивается по кнопке в разделе «Перевод».

## Где данные

Клиенты, записи, абонементы, заметки и настройки хранятся **в самом приложении на этом устройстве** (IndexedDB) — не на сервере и не у разработчика. Раз в день приложение само делает копию внутри себя (30 последних). Раздел «Данные» → «Сохранить копию в „Файлы“» сохраняет файл JSON в «Файлы» или iCloud Drive; его же можно загрузить в Windows-версию, веб-версию или на другой iPhone. Если удалить Кушетку с экрана «Домой», iOS сотрёт и её данные — сохраняйте копию.

## Библиотека

Тексты книг, индекс поиска, картинки справочников, база продуктов и модель перевода лежат в этом же репозитории, в папке `library/` (список файлов — `library.json`), и скачиваются в приложение — входить никуда не нужно. PDF книг лежат в папке на Google Диске владельца, открытой по ссылке: кнопка «PDF» открывает книгу на Google Диске в Safari (с первой страницы, нужен интернет). В библиотеке только книги под открытыми лицензиями (Creative Commons, общественное достояние, OGL, официальные документы); закрытые книги в приложении видны описанием и ссылкой на источник.

## Устройство

Страница та же, что у Windows- и веб-версии Кушетки. Service worker (`sw.js`) хранит приложение для работы без интернета и выполняет роль «помощника» Windows-версии: данные — в IndexedDB, библиотека — из `library/` с кэшем на устройстве, перевод — движок Bergamot (Mozilla) прямо на устройстве.

Эта папка собирается скриптом `ios/build.py` из исходников Кушетки. Лицензии компонентов и данных — `LICENSES.txt`.
